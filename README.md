# Knight Game

A 2D platformer game developed using Godot Engine.  
This project was created as a game development portfolio project to demonstrate gameplay programming, scene management, player mechanics, and level design fundamentals.

---

## 🎮 Features

- Smooth player movement
- Jump mechanics
- Enemy interactions
- Collision and physics handling
- Animated character system
- 2D platformer environment
- Score / progression mechanics

---

## 🛠️ Built With

- Godot Engine
- GDScript
- Pixel Art Assets
- TileMaps and 2D Physics

---

🚀 How to Run the Game
Clone the repository:
git clone https://github.com/SwaatiR/Knight_game.git
Open the project in Godot Engine
Run the main scene
